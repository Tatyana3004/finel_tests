# Тесты на проверку оформления заказа и получение трек номера заказа
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest
- фаил Configuration.py содержит URL - адрес, путь к Api методу на создание нового заказа и получения номера заказа по его трек номеру.
- фаил data.py содержит запрос на создание заказа
- фаил sendar_stend_request.py содержит функции на создание нового заказа и получение его номера по трек номеру
- фаил test_orders.py содержит позитивный и негативные тесты
